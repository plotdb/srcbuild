recipe (沒有 s), 與 src, static 同層

需要有雙向對應
 - 如何生成 html  ( build(files) )
   - 未給定參數時, 全量重建
   - 參數可為單檔 (string) 或多檔 (list of string)
 - 來源檔變更時觸發 ( watch(), 可用做資料快取等機制 )
 - 哪些來源檔案會觸發哪些目標檔案的重建 ( sources(file), 預設回傳所有相依檔, 或對應檔案的相依檔 )
   - srcbuild 可基於無參數傳回值 files = sources() 建立 watch
 - 需能查詢某目標檔是否源於此 recipe ( match(file), 回傳 true / false) )
 - 是否需要重建 ( dirty(file), 回傳 true / false. 若不 match, always false )

建構模式:
 - manual: 一次性執行所有必要的檔案生成.
 - lazy: 請求 file 時, 該路徑若屬於此 recipe, 且 file 不存在或比對應來源舊, 就觸發生成
